About Us

College Event Hub is a simple web platform created to share information about college events like sports, trainings, and cultural programs.

This project has been developed strictly for educational purposes as part of a learning journey in frontend web development.
It is created by Samir Gosain with the primary objective of enhancing practical understanding of HTML, CSS, and JS.

The project focuses on building a clean, responsive, and user-friendly interface while improving skills in layout structuring, styling, and basic interactivity.
It reflects continuous learning and hands-on practice in developing modern web pages and improving overall frontend development knowledge.
